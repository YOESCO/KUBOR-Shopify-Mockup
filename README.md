# KUBOR Shopify Mockup

Repositorio público dedicado a visualizar el sistema UI/UX del nuevo KUBOR Shopify Theme sin tocar el repositorio productivo ni el trabajo activo de Codex.

## Objetivo
Validar en HTML/CSS/JS el shell global y, después, las páginas Home, PLP y PDP antes de traducir el diseño aprobado a Liquid/Shopify.

## Incluye ahora
- Topbar.
- Header sticky.
- Mega menú desktop.
- Menú móvil drawer.
- Cart drawer.
- Predictive search drawer.
- Account drawer.
- Filter drawer.
- Footer modular.
- Responsive.
- Toggle claro/oscuro para pruebas de contraste.

## Logos
Los logos no se generan con IA. Se usan copias SVG optimizadas a partir de los archivos originales entregados por el usuario, conservando geometría y colores.

## GitHub Pages
Este repo es público y el sitio está en la raíz (`index.html`), por lo que puede publicarse directamente con GitHub Pages usando `main` / root.

## Regla
Este repositorio es un mockup visual. No es código productivo de Shopify y no debe sustituir ni modificar el theme hasta que el usuario apruebe cada bloque visual.
