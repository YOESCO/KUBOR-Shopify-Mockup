## Shared shell

All pages reuse:

- announcement bar
- header
- navigation / mega menu
- mobile drawer
- predictive search
- account drawer
- cart drawer
- footer
- button system
- icon system
- media component
- product-card component
- trust blocks
- motion primitives

## Home depth target

Home should feel richer without becoming a long collection of unrelated banners. Recommended order:

1. hero
2. category / discipline navigation
3. featured product or launch
4. best sellers / product rail
5. editorial brand story
6. technology / engineering block
7. choose-your-bike / buying guide
8. category spotlight or collection campaign
9. dealer/distributor CTA
10. community / editorial content
11. trust/service strip
12. newsletter
13. footer

Optional seasonal campaign blocks can be inserted between 3–9.

## Build priority rule

Do not complete every secondary page before validating the end-to-end commerce path. First make Home → PLP → PDP → Cart → Search coherent and functional. Then extend the same system to discovery, support, content, and account pages.

## Consistency rule

A pattern used on more than one page should be promoted to a reusable component before a third copy is created. This prevents divergence during the later Shopify conversion.
