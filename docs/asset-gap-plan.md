# Asset Gap Plan — KUBOR Mockup

Status: active asset-convergence workstream.

## Rule

Do not present generated lifestyle/concept imagery as an actual KUBOR model packshot. Product cards and PDP media can only be considered visually approved once the image is traceable to the real model/variant or to an explicitly approved concept product.

## Asset tiers

### A. Owned / approved brand assets
- Official KUBOR SVG logos already in `assets/logos/`.
- Official Terrafit and HYPERGOGO logo files are available in the user Library and should replace text placeholders when published into the repo.
- KUBOR lifestyle imagery from the user Library can be used for hero, campaign, storytelling, discipline landings and brand modules.

### B. Real product imagery
Priority models for real packshot extraction / sourcing:
1. Alpine
2. Calypso / Calypso 3 / Calypso 4
3. Mallory
4. Tornado
5. Storm
6. Sierra 7
7. Venus / Cosmo
8. Alien / Octopus
9. Volt Rider / Cybertrike where applicable

Known real source already located in the Library:
- Mallory R29 PDP staging screenshot with an orange KUBOR bike. This is suitable as evidence/source material, but should be cropped/cleaned only if the resulting image still faithfully represents the real product.

### C. Concept / portfolio imagery
Portfolio decks contain useful studio lineups and concept bikes. These may be used for portfolio strategy, future-product storytelling or campaign mockups, but must not silently replace current production-model photography.

### D. Temporary third-party imagery
Unsplash remains allowed only as a clearly temporary placeholder for discipline/editorial modules where no owned image exists yet. It is the first class of imagery to remove during final visual convergence.

## Current asset replacements

- `assets/media/kubor-hero.jpg` — optimized KUBOR lifestyle image prepared for Home hero / MTB storytelling. It is a brand lifestyle asset, not an X1 Pro packshot.

## Required image families before visual approval

### Home
- desktop hero crop
- mobile hero crop
- MTB / Road / Gravel / Urban / Electric category imagery
- technology / community / support banners

### PLP
- collection hero by discipline
- consistent product packshots on neutral background
- optional editorial insertion image

### PDP per model
- primary lateral packshot
- 3/4 view
- opposite side where relevant
- suspension / fork detail
- cockpit detail
- drivetrain / crankset / cassette detail
- brake / rotor detail
- wheel / tire detail
- frame detail / cable routing
- lifestyle image
- geometry diagram if approved

## Approval gate

A Home/PLP/PDP surface is not asset-approved while it relies on generic imagery that visually implies a specific KUBOR model without evidence that it is that model.
